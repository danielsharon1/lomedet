# לומדת למבחן 📚

אפליקציית תרגול למבחנים – שאלונים (כולל נכון/לא נכון), כרטיסיות, סימולציית מבחן עם טיימר, התקדמות ונקודות חולשה, תזכורת יומית וגיבוי.

- **אנדרואיד:** [הורדת האפליקציה (APK)](https://github.com/danielsharon1/lomedet/releases/latest/download/lomedet.apk)
- **אייפון / מחשב:** https://danielsharon1.github.io/lomedet/ (באייפון: שיתוף ← "הוסף למסך הבית")

## איך מעדכנים – וכולם מקבלים את העדכון

1. נכנסים לתיקייה `questions/` ופותחים את קובץ הקורס (למשל `kashrut.txt`).
2. לוחצים על העיפרון ✏️, מוסיפים/מתקנים שורות לפי ההסבר שבראש הקובץ, ולוחצים **Commit changes**.
3. תוך כ-3 דקות GitHub בונה אוטומטית ומעדכן:
   - **את האתר** – מי שפותח את האפליקציה (במחשב או בטלפון) מקבל את הגרסה החדשה בפתיחה הבאה.
   - **את אפליקציית האנדרואיד** – האפליקציה בודקת עדכונים בכל פתיחה ומתעדכנת לבד, בלי להתקין מחדש.
4. קורס חדש: מוסיפים אותו ל-`questions/courses.json` ויוצרים קובץ `questions/<id>.txt`.

אם יש טעות בקובץ (למשל חסר חלק בשורה) – הבנייה נעצרת, אף משתמש לא מקבל גרסה שבורה, ובלשונית **Actions** מופיע בדיוק איזו שורה לתקן.

## מבנה
- `questions/` – השאלות והקורסים (זה מה שעורכים)
- `src/` – קוד האפליקציה · `tools/build.py` – בונה את `www/`
- `assets/` – אייקון ומסך פתיחה · Capacitor – עטיפה כאפליקציית אנדרואיד
- `tools/native_min.txt` – מעלים רק כשמשנים יכולות נייטיב (ואז האפליקציה תבקש להוריד APK חדש)
